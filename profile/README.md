## What Is Statgraphics Centurion

Statgraphics Centurion is a Windows statistics suite aimed at industrial and quality work. Process engineers who already log measurements open Statgraphics Centurion quality stats to design an experiment, chart a process, or estimate capability. Statgraphics Centurion DOE is the design. Statgraphics Centurion control chart is the shop-floor picture. Statgraphics Centurion process stats is the project you keep with the line’s SOP.

JASP and jamovi are academic GUIs. PSPP is survey syntax. SigmaPlot is a journal figure. This product is the plant: gage studies, reliability, DOE, SPC. If the dataset is a psychology Likert file, you are in the wrong building.

Use data from processes you operate, trials you ran, or a plant that hired you. Keep projects with the batch record. Do not publish another factory’s unpublished capability as a demo.

## Starting with Statgraphics Centurion

Prerequisites: A PC you administer and process measurements from a line you are allowed to study.

1. **Prepare:** Pull subgroups and factor logs from the system you already operate, with batch IDs intact.
2. **Configure:** Create Statgraphics Centurion process stats named after that line and product.
3. **Test:** Build one Statgraphics Centurion control chart and match a known out-of-control point you already documented.
4. **Refine:** Plan Statgraphics Centurion DOE only on factors the plant can actually change.
5. **Apply:** Run capability in Statgraphics Centurion quality stats for the spec the customer already signed.
6. **Maintain:** Archive with the SOP revision, and start a new file after a major process change.
